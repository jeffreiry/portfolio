## Gaps prioritários

### 🔴 Bloqueadores de candidatura

**1. Ausência total de experiência com Unreal Engine (UMG) ou engine equivalente**

Este é o bloqueador mais duro da candidatura. A vaga não pede familiaridade conceitual com game engines — ela exige que o candidato implemente UI Art diretamente em Unreal Engine usando UMG, crie lógica básica em blueprints e gere materiais e animações dentro do engine. Isso é uma competência técnica específica que não tem substituto no portfolio de Jeferson: Power Apps é uma plataforma low-code Microsoft para aplicações corporativas sem nenhuma sobreposição funcional com o pipeline de arte de games em Unreal. Não há como mitigar esse gap na candidatura atual — seria necessário construir um projeto pessoal ou de portfólio em Unreal Engine com UMG antes de aplicar para qualquer vaga desse perfil.

**2. Ausência de motion design, UI animation e UI materials/shaders**

A vaga descreve um perfil que não é apenas designer de interfaces estáticas: é um artista que anima UI, cria efeitos visuais, constrói materiais dinâmicos e shaders dentro de um pipeline de arte. Nenhum case de Jeferson documenta motion design ou animação de UI. Cartela Cores trabalha com sistema de cores estático. A única referência próxima seria interaction design, mas nenhum case documenta protótipos animados, micro-interações ou transições. Esse gap elimina a candidatura no nível técnico de arte, independente do restante do portfolio. Mitigação parcial possível apenas com produção de um case específico mostrando UI animada — por exemplo, um projeto pessoal em After Effects, Rive ou Figma prototyping avançado com animações explicitamente documentadas.

**3. Portfolio sem artefatos visuais expostos publicamente**

UI Artist é uma vaga onde o portfólio visual é o critério principal de triagem — recrutadores de arte em game studios avaliam pixel a pixel a qualidade estética antes de ler qualquer texto. O portfolio de Jeferson documenta processo em texto e possui cases bem estruturados metodologicamente, mas não expõe telas, mockups, UI finals, ícones, motion ou qualquer artefato visual navegável. Para uma vaga de UI Artist na Epic Games, essa ausência é bloqueadora: sem ver a qualidade visual do trabalho, não há candidatura. Isso se distingue de vagas de UX Research ou Product Design estratégico onde processo documentado pode compensar ausência de artefatos — aqui a arte visual é o produto entregável central.

**4. Ausência de paixão declarada por games e player empathy**

A Epic Games é explícita ao incluir "passion for making and playing games" como requisito obrigatório. Isso não é um diferencial cultural opcional — é um filtro de fit com a missão da empresa. O portfolio de Jeferson não contém nenhuma referência a games: nem projetos pessoais, nem menções a influências de game design, nem contexto que situe o candidato nessa cultura. Para uma empresa cujo produto central é Fortnite e Unreal Engine, esse desalinhamento de domínio é estrutural e não pode ser mitigado apenas com argumentação — precisaria de evidência real de engajamento com games.
